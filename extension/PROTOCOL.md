# Frozen computational extension protocol v1 — 18 October 2026

Purpose: test two separate finite assertions: (A) exact premium rho(G,B)-beta2(G)<=1 under selected unequal positive edge lengths or changed topologies, for EVERY minimum ordinary basis of each tested graph; (B) deterministic distinguishability of exact-optimal layouts under bounded additive reading error. No universal generalisation or physical validation follows from passing cases.

Input: immutable pilot graphs.jsonl, retain all records with 3<=n<=8 in file order. Labels 0..n-1 and edges sorted lexicographically. Input graph classes were exhaustively deduplicated in the original pilot; this extension is a deterministic labelled sample of variants, NOT exhaustive weighted/topology coverage. Duplicate resulting variants are retained and identified, not counted as nonisomorphic classes.

Families in order:
1. baseline: each retained graph with unit lengths.
2. weighted: for each retained graph, three assignments from a fresh Python random.Random(20261018) shared sequential stream; each sorted edge receives randint(1,4). If assignment is constant, change its first weight to 1+(weight mod 4). Thus every assignment is unequal, positive integer and fully stored.
3. degree4: for each retained graph of order <=7 having a degree3 vertex, attach one new leaf to its smallest-labelled degree3 vertex. Keep unit lengths. This preserves exactly one cycle and introduces maximum degree4.
4. bicyclic: for each retained graph, add its lexicographically first nonedge whose endpoints both have degree<=2, if one exists. Unit lengths; maxdegree<=3 and cycle rank2. This isolates the one-cycle assumption.

Freeze all planned cases before solving; use deterministic IDs. Within each nonbaseline family stop exact solving at its first independently verified p>1 counterexample; explicitly record all remaining cases as skipped by that rule. Continue other independent families. Stop whole block if resource ceiling reached. No widening or adaptive search.

Exact core: integer Floyd-Warshall distances; exhaustive 2^n subsets; a resolving subset has >=1 distinguishing selected coordinate per unordered vertex pair; FT has >=2. Enumerate all minimum resolving bases, unconstrained FT optimum and smallest-mask minimum FT superset of EACH basis. Preserve edge triples, distances, bases, optimum witnesses, and every subset's resolving/FT flags. All n<=8 here (including added leaves).

Independent verification in same bounded process: Dijkstra via heap against every distance row; independent tuple-signature uniqueness for resolving and explicit deletion of EACH selected coordinate for FT, requiring size>=2. Compare the entire subset table and recompute all optima/superset optima from that independent table. This is independent code, not an independent human/agent audit. Any disagreement aborts. Verify baseline optima against saved original pilot summaries. Check triangle and weighted triangle hand fixtures before samples.

Noise: each retained sensor reading is d(v,s)+e_s with |e_s|<=epsilon independently/adversarially; vertex identities and graph distances fixed. One identified sensor erasure deletes a coordinate, not a graph vertex; no distance recomputation. For a layout S define m1=min_pairs max_s |d(u,s)-d(v,s)|, m2=min_pairs second-largest_s |d(u,s)-d(v,s)| (0 if |S|<2). Guaranteed unique localisation before loss iff m1>2epsilon; after any one loss iff m2>2epsilon. This follows from nonoverlap of closed error boxes, requires STRICT inequality; equality is not robust. Evaluate epsilon in {0,1/4,1/2,1} exactly via integer cross multiplication. Report m1,m2 and flags for every minimum basis, its deterministic minimum FT augmentation, and one smallest-mask unconstrained FT optimum, for every solved case. No Gaussian/stochastic claim and no physical unit calibration. Absolute margins across unequal total graph lengths do not establish practical improvement.

Resource cap: single process, one CPU affinity, Windows Job Object 1000 user-CPU seconds, wall watchdog 1100 seconds, 3,300,000,000-byte job commit and 3,000,000,000-byte hard working-set cap. Cooperative total process user+kernel CPU stop at 1100 seconds; watchdog and single-core affinity bound work below 1200 CPU seconds, with headroom for launch/packaging. Log measured CPU, working set and commit peaks. No children, GPU, network or paid tools. Existing limit implementation copied unchanged; fail closed if installation fails. No automatic rerun after any scientific launch.

Reproduction: python extension-001/run_extension.py from workspace root. Code, protocol and input hashes frozen in freeze.json before launch; script verifies them and refuses an existing run manifest. A reviewer must copy sources/inputs to a fresh directory and explicitly supply a fresh bounded budget to rerun. Record environment, start/end, statuses, checksums and all skipped cases. No original source or final manuscript edits. Deliver standalone report, proposed addendum and source/results ZIP for review; no publication or Library upload requested in this extension.
